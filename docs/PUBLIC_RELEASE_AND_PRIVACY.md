# 公开发布与脱敏说明

## 公开内容

- 模型结构、训练循环、损失函数和公开数据适配代码。
- FSDP多卡启动脚本。
- 仅包含路径占位符的配置文件。
- SAM掩码预计算工具。

## 明确排除

- 四中心腰椎MRI切片及任何原始DICOM/NIfTI。
- 标签CSV、病例编号、医院信息和可关联患者的元数据。
- SAM及自监督模型权重。
- Checkpoint、Embedding、训练日志、可视化结果和实验输出。
- 医学图像和患者元数据；
- 权重或大文件；
- 没有未说明来源的第三方代码。

## 使用边界

该仓库仅用于科研复现和工程展示。任何医学数据使用必须遵守伦理审批、
数据使用协议和当地法规，输出不得作为自主诊断或治疗依据。
